Methodology

  1. Bytes are the on-disk size of the .js file (pre-gzip, post-minify).
  2. Package attribution is approximated from source-map `sources` (file-count share per chunk).
  3. Pages are detected from `page-<id>.<hash>.chunk.js` filenames produced by `webpackChunkName` magic comments.
  4. Empty sections are omitted from both JSON and HTML — if a section is missing, the data was absent.
