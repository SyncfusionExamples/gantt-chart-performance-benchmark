# React Gantt Chart Performance Benchmark

A comprehensive performance benchmarking suite for comparing popular Gantt chart libraries in React applications.

## Overview

This project measures and compares the performance characteristics of industry-leading Gantt chart libraries, providing insights into rendering speed, memory usage, and responsiveness across various scenarios.

## Tested Libraries

The following Gantt chart libraries are included in this benchmark:

| Library                  | Version             | Notes                |
|--------------------------|---------------------|----------------------|
| Syncfusion Gantt         | 0.1.0               | Enterprise solution  |
| DHTMLX Gantt             | 0.1.0               | Open-source library  |
| Bryntum Gantt            | 7.3.5               | Trial version        |

## Getting Started

### Installation

```bash
npm install
```

### Running Benchmarks

```bash
npm run benchmark
```

## Features

- Performance metrics comparison across multiple libraries
- Real-world scenario testing
- Memory usage analysis
- Rendering performance evaluation
